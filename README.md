# Mi Primera App Expo

Aplicación móvil desarrollada con React Native y Expo.

## Requisitos

Antes de ejecutar el proyecto se debe tener instalado:

* Node.js versión 20 o superior.
* Expo Go en un dispositivo móvil Android o iOS.

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/tatiana5mafo-png/mi-perfil.git
```

Entrar a la carpeta del proyecto:

```bash
cd mi-perfil
```

Instalar las dependencias:

```bash
npm install
```

## Ejecutar la aplicación

Iniciar el proyecto con Expo:

```bash
npx expo start
```

Después de ejecutar el comando, aparecerá un código QR. Se debe escanear desde la aplicación **Expo Go** en el celular para abrir la aplicación.

## Tecnologías

* React Native
* Expo
* JavaScript
